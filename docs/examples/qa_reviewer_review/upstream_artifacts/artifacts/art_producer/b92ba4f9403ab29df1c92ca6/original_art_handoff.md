# Art Producer handoff

Initial Time Loop art package: 12 reusable raster placeholder assets covering the player, ghost replay silhouette, level tileset, switch, pressure plate, door, laser emitter/beam, enemy, exit crystal, HUD panel with timeline track, UI buttons plus ghost timeline markers and clock hand, and a title backdrop with overlapping clock hands and ghost silhouettes. Both mounted libraries reported available=false in this environment, so no library paths or licenses are claimed; every asset is an image-service placeholder (mock-image.v1) generated to final target dimensions so Developer can integrate now. Libraries remain permitted for later replacement, and all generated visuals are placeholders pending final visual acceptance. No engine run, screenshot inspection, or gameplay/visual quality verification is claimed.

## Style guide

Cohesive 2D side-view 'clockwork pastel' look: 32x32 tile grid, flat-shaded shapes with 1-pixel dark outline, limited palette of deep indigo background (#1B1E3A), warm amber accents (#F2B441), cool cyan for player and interactables (#4FC3D9), and muted violet for ghost silhouettes (#9B7BFF at 55% alpha). Ghosts read as translucent silhouettes, never as a recolor of the player's exact body. All raster assets use nearest filtering and integer scaling (1x native, 2x/4x for display) to keep pixel edges crisp at the fixed 1280x720 viewport. Four chapter variants are produced by runtime modulate tint on the shared tileset and UI: Chapter 1 amber, Chapter 2 teal, Chapter 3 magenta, Chapter 4 pale gold. Interactive state changes are expressed by swapping to the 'on'/'active' frame and adding a short tint pulse; no per-state art is generated beyond the two-frame cells below. Font: Godot built-in default font is used because no library font pack is available in this environment; do not bake text into any sprite.

## Limitations

- Images were checked for file format and dimensions, not visually reviewed or integrated into a game.
- Mock-generated images are test placeholders and do not fulfill final artwork requirements.
